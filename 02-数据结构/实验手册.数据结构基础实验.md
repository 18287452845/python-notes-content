## 数据结构基础实验手册

本手册依据第 02 章《数据结构》讲义（第 08、09、10、12、13 讲，不含第 11 讲字符串）编制，用于课后基础训练与上机实验。手册由实验总则、五个实验单元和三个附录构成：客观题（概念判断、程序阅读、程序填空、程序改错）用于检验对概念与代码细节的掌握程度，编程实验题用于训练独立编写程序的能力。字符串在本手册中仅作为普通数据出现（例如作为字典的键或集合的元素），不考查字符串自身的方法。本手册与《实验2.数据结构综合实验》互补：前者侧重基础夯实，后者侧重完整案例的综合运用。

## 实验总则

## 附录A 四种容器特性对照表

| 对照项 | 列表（list） | 元组（tuple） | 集合（set） | 字典（dict） |
| ---- | ---- | ---- | ---- | ---- |
| 字面量示例 | `[1, 2, 3]` | `(1, 2, 3)` | `{1, 2, 3}` | `{'a': 1, 'b': 2}` |
| 有序性 | 有序 | 有序 | 无序 | 按插入顺序遍历（Python 3.7 起） |
| 可变性 | 可变 | 不可变 | 可变 | 可变 |
| 索引运算 | 整数索引，含负索引 | 整数索引，含负索引 | 不支持 | 用键作索引 |
| 重复性 | 元素可重复 | 元素可重复 | 元素不可重复 | 键不可重复，值可重复 |
| 成员运算 `in` | 按元素判断 | 按元素判断 | 按元素判断，速度快 | 按键判断，速度快 |
| 空容器写法 | `[]` 或 `list()` | `()` | `set()` | `{}` |
| 生成式语法 | `[x for x in ...]` | 无，可转换列表生成式 | `{x for x in ...}` | `{k: v for ...}` |
| 典型用途 | 有序记录、增删改、排序 | 固定不变的成组数据 | 去重、交并差运算 | 按键检索、频次统计 |

注意事项：一元组必须写作 `(x,)`；`{}` 是空字典而不是空集合；集合与字典的键都要求不可变（可哈希）类型。

## 附录B 常用方法速查表

列表的常用方法（`items` 代表一个列表）：

| 方法 | 说明 |
| ---- | ---- |
| `items.append(x)` | 在列表末尾追加一个元素 |
| `items.insert(i, x)` | 在索引 `i` 的位置插入元素 `x`，后面的元素依次后移 |
| `items.extend(lst)` | 把列表 `lst` 中的元素全部追加到列表末尾 |
| `items.remove(x)` | 删除第一个等于 `x` 的元素，元素不存在引发 ValueError |
| `items.pop(i)` | 删除并返回索引 `i` 位置上的元素，省略 `i` 时删除最后一个元素 |
| `items.clear()` | 清空列表中的所有元素 |
| `items.index(x)` | 查找元素 `x` 第一次出现的索引位置，找不到引发 ValueError |
| `items.count(x)` | 统计元素 `x` 在列表中出现的次数 |
| `items.sort()` | 对列表中的元素排序，默认从小到大 |
| `items.reverse()` | 把列表中的元素反转 |
| `items.copy()` | 复制列表，得到一个新的列表 |

集合的常用方法与运算（`s`、`t` 代表集合）：

| 方法或运算 | 说明 |
| ---- | ---- |
| `s.add(x)` | 添加元素，元素已存在则集合不变 |
| `s.remove(x)` | 删除元素，元素不存在引发 KeyError |
| `s.discard(x)` | 删除元素，元素存在与否都不引发异常 |
| `s.pop()` | 随机删除并返回一个元素 |
| `s.clear()` | 清空集合 |
| `s.update(t)` | 并入另一个集合，等价于 `s \|= t` |
| `s.issubset(t)` / `s.issuperset(t)` | 判断子集 / 超集，对应运算符 `<`、`<=`、`>`、`>=` |
| `s.isdisjoint(t)` | 判断两集合是否有共同元素 |
| `s & t`、`s \| t`、`s - t`、`s ^ t` | 交集、并集、差集、对称差，也可用同名方法 |

字典的常用方法（`d` 代表字典）：

| 方法 | 说明 |
| ---- | ---- |
| `d.get(k, default)` | 通过键取值，键不存在返回 None 或默认值，不引发异常 |
| `d.keys()` / `d.values()` / `d.items()` | 获取所有键 / 所有值 / 所有键值对，`items` 的元素是二元组 |
| `d.update(other)` | 合并另一个字典，同名键的值被覆盖 |
| `d.pop(k)` | 删除指定键的键值对并返回对应的值，键不存在引发 KeyError |
| `d.popitem()` | 删除并返回最后一组键值对（二元组） |
| `d.clear()` | 清空字典 |
| `del d[k]` | 删除键值对；`del` 是 Python 关键字，不是方法 |

### 知识点总结

#### 一、四种容器的概念与选型依据

- 列表：有序、可变、元素可重复；适合保存需要按顺序处理、需要增删改或排序的数据，如名册、成绩序列。
- 元组：有序、不可变；适合保存固定不变、成组出现的数据，如学号与姓名的组合、坐标。
- 集合：无序、可变、元素不可重复；适合去重以及交、并、差等集合运算，成员判断速度快。
- 字典：以键值对组织数据，键必须是不可变类型且不重复，值可以是任意类型；适合按键快速检索和频次统计。
- 选型依据：是否需要顺序、是否需要修改、是否需要去重、是否按键检索，四个问题依次回答即可确定容器类型。

#### 二、创建方式与生成式

- 列表：`[]` 字面量、`list()` 构造器、空列表 `[]`；元组：`()` 字面量、`tuple()` 转换；集合：`{元素}` 字面量、`set()`（空集合必须用 `set()`）；字典：`{键: 值}` 字面量、`dict()`、`dict(zip(键序列, 值序列))`。
- 一元组必须写作 `(x,)`；`{}` 是空字典；`list()`、`tuple()`、`set()`、`dict()` 都是构造器而非普通函数。
- 生成式家族：`[x for x in ... if 条件]`、`{x for x in ...}`、`{k: v for ...}`，强烈建议优先使用生成式创建列表、集合与字典，写法简洁且性能更优。

#### 三、索引、切片与成员运算

- 正向索引从 0 到 N-1，反向索引从 -1 到 -N；索引越界引发 IndexError。
- 切片 `[start:end:stride]` 含起始位置、不含终止位置；三个分量均可按规则省略；步长为负时从右向左取值；切片结果是同类型的新容器；列表还支持切片赋值，可一次替换多个元素。
- 字典用键作索引；键不存在时 `[]` 引发 KeyError，`get` 返回 None 或默认值；集合不支持索引运算。
- `in` 与 `not in` 适用于全部四种容器；字典与集合的成员运算在性能上优于列表和元组；字典的成员运算判断的是键。

#### 四、常用方法与典型异常

- 列表：append、insert、extend、remove、pop、clear、index、count、sort、reverse、copy；`del items[i]` 是关键字操作，不是方法。
- 集合：add、remove、discard、pop、clear、update、issubset、issuperset、isdisjoint；运算符 `&`、`|`、`-`、`^` 对应交、并、差、对称差。
- 字典：get、keys、values、items、update、pop、popitem、clear；遍历键值对的惯用写法是 `for key, value in d.items():`。
- 异常对照：索引越界与 `pop` 索引越界为 IndexError；`remove`、`index` 找不到目标以及解包个数不符为 ValueError；修改元组元素、用可变类型作键或集合元素为 TypeError；字典与集合按缺失的键删除或访问为 KeyError。
- 访问或删除可能不存在的数据前，先用 `in` 判断，或改用 `get`、`discard` 等不引发异常的方法。

#### 五、可变性、赋值与复制

- `nums2 = nums1` 不产生新列表，只是给同一个对象起了两个名字，通过任一变量修改，另一个也可见。
- 独立副本使用 `copy()` 或切片 `[:]`；嵌套结构中的内层对象仍然共享（浅拷贝），修改内层列表时需特别小心。
- 元组的不可变指不能替换其中的元素引用；若元组内保存了列表，该列表自身仍可修改，这与"元组不可变"并不矛盾。

#### 六、命名规则与代码风格

- 容器类型的变量名使用复数形式：`scores`、`names`、`counters`、`students`；元素变量用单数形式，如 `for score in scores:`。
- 计数列表习惯初始化为 `[0] * N`；"数据值到下标"的映射（如 `face - 1`、`total - 2`）是计数程序的关键，必要处加注释。
- 只需要元素时直接 `for x in items:` 遍历；需要下标时才用 `for i in range(len(items)):`。
- 随机数程序每次输出可能不同，示例输出只代表一次运行，报告中应记录多次运行结果。

#### 七、复习时的易错点

- 把首元素的索引记成 1；把 -1 误解为倒数第二个元素。
- 忘记切片"含头不含尾"；混淆索引（返回元素）与切片（返回容器）。
- 混用 append 与 extend，导致出现嵌套列表。
- 一元组漏写逗号，`(100)` 是整数而不是元组。
- 把 `{}` 当作空集合使用，实际得到的是空字典。
- `remove` 只删除第一个匹配元素；删除前不判断存在性导致 ValueError 或 KeyError。
- 把赋值当作复制，出现"改了一个另一个也变"的现象。
- 用列表作字典的键或集合的元素；遍历字典时误以为循环变量是键值对。

#### 八、学习重点

- 能默写四种容器的字面量写法、空容器写法与构造器转换方式。
- 能徒手推演包含索引、切片与常用方法的短程序的输出，并用上机运行验证。
- 能按数据特征完成容器选型，把"循环加 append 构造列表"的代码改写为生成式，并用字典的 get 模式完成频次统计。
