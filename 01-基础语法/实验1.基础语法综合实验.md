# 实验1.基础语法综合实验

## 基础语法综合实验

本实验把**变量与类型、运算符、分支结构、循环结构**串成一个可运行的小程序：成绩录入与统计控制台。请先完成 `01-基础语法` 中相关讲义，再动手实现。

### 实验目标

1. 能用变量保存姓名、分数等数据，并正确选择 `int` / `float` / `str`。
2. 能用算术运算求平均分、及格率，用比较和逻辑运算做条件判断。
3. 能用 `if` / `elif` / `else` 实现成绩等级划分，用循环和菜单驱动程序。
4. 能用 `for-in`、`while`、`break`、`continue` 完成录入、统计和退出。

### 实验任务

编写程序 `score_console.py`，提供一个文字菜单：

1. 录入成绩（可连续录入多个，输入 `q` 结束本轮）
2. 查看全部成绩
3. 统计信息（平均分、最高分、最低分、及格人数、不及格人数）
4. 按等级查看（A/B/C/D/F）
5. 退出程序

等级规则（百分制）：

| 分数区间 | 等级 |
| -------- | ---- |
| 90 ~ 100 | A |
| 80 ~ 89 | B |
| 70 ~ 79 | C |
| 60 ~ 69 | D |
| 0 ~ 59 | F |

输入不在 0～100 时提示“分数无效”，不写入成绩列表。

### 参考实现

```python
"""
成绩录入与统计控制台
覆盖：变量与类型、运算符、if 分支、for/while 循环
"""

scores = []

while True:
    print('====== 成绩管理 ======')
    print('1. 录入成绩')
    print('2. 查看全部成绩')
    print('3. 统计信息')
    print('4. 按等级查看')
    print('5. 退出')
    choice = input('请选择操作（1-5）：').strip()

    if choice == '1':
        while True:
            raw = input('请输入 0~100 的成绩（输入 q 结束本轮）：').strip()
            if raw.lower() == 'q':
                break
            # 用 isdigit 快速过滤：成绩按整数录入，便于初学者理解
            if not raw.isdigit():
                print('分数无效，请输入整数或 q。')
                continue
            score = int(raw)
            if score < 0 or score > 100:
                print('分数无效，必须在 0~100 之间。')
                continue
            scores.append(score)
            print(f'已录入：{score}，当前共 {len(scores)} 条成绩。')

    elif choice == '2':
        if not scores:
            print('暂无成绩，请先录入。')
        else:
            for i in range(len(scores)):
                print(f'{i + 1}. {scores[i]}')

    elif choice == '3':
        if not scores:
            print('暂无成绩，请先录入。')
        else:
            total = 0
            max_score = scores[0]
            min_score = scores[0]
            pass_count = 0
            for score in scores:
                total += score
                if score > max_score:
                    max_score = score
                if score < min_score:
                    min_score = score
                if score >= 60:
                    pass_count += 1
            fail_count = len(scores) - pass_count
            average = total / len(scores)
            pass_rate = pass_count / len(scores) * 100
            print(f'人数：{len(scores)}')
            print(f'平均分：{average:.2f}')
            print(f'最高分：{max_score}')
            print(f'最低分：{min_score}')
            print(f'及格：{pass_count} 人，不及格：{fail_count} 人')
            print(f'及格率：{pass_rate:.1f}%')

    elif choice == '4':
        if not scores:
            print('暂无成绩，请先录入。')
        else:
            level = input('请输入等级（A/B/C/D/F）：').strip().upper()
            if level not in ('A', 'B', 'C', 'D', 'F'):
                print('等级无效。')
                continue
            found = False
            for score in scores:
                if score >= 90:
                    current = 'A'
                elif score >= 80:
                    current = 'B'
                elif score >= 70:
                    current = 'C'
                elif score >= 60:
                    current = 'D'
                else:
                    current = 'F'
                if current == level:
                    print(f'{score} -> {current}')
                    found = True
            if not found:
                print(f'没有 {level} 等级的成绩。')

    elif choice == '5':
        print('再见！')
        break

    else:
        print('无效选项，请重新选择。')
```

### 操作示例

假设依次录入 `95`、`82`、`67`、`45`，然后选择统计，应看到：

```text
最高分：95
最低分：45
及格：3 人，不及格：1 人
及格率：75.0%
```

选择等级 `B` 时应输出：`82 -> B`。

### 知识点总结

1. **变量与类型**：`scores` 用列表保存多条成绩；`input` 得到的永远是字符串，参与数值运算前要用 `int()` 转换；`len(scores)`、`total` 等保存中间状态。
2. **运算符**：`/` 得到浮点平均分，`* 100` 计算百分比；`>=`、`and`、`or`、`not` 用于范围校验；`in` 判断菜单选项是否合法；`+=` 累加。
3. **分支结构**：外层菜单用多分支 `if-elif-else`；等级划分用**从高到低**的 `elif` 链，保证每个分数只命中一个等级；非法输入用 `continue` 回到循环开头，而不是让程序崩溃。
4. **循环结构**：外层 `while True` 做菜单；录入环节用内层 `while` + `break` 结束本轮；用 `for` + `range` 按下标打印，用 `for score in scores` 做统计。
5. **程序结构**：先清空列表再进入主循环；每个分支先判断“有没有数据”，再做计算，避免空列表导致 `scores[0]` 出错。
6. **易错点**：忘记把 `input` 转成数字；`elif` 条件顺序写反（如先判 `>=60` 再判 `>=90`）；比较时混用 `=` 与 `==`；不及格判断写成 `score < 60 or score > 100` 却没有先排除无效分。
7. **学习重点**：能独立写出“菜单 + 循环 + 分支 + 列表统计”的最小完整程序，这是后续数据结构和函数实验的语法底座。
