# 17.函数高级应用

## 函数高级应用

> **说明**：本讲内容全部属于**提高部分，课上不讲**，请课后自己阅读并动手练习。它们能让你的代码写得更漂亮，但不影响对前面基础内容的掌握，也不影响你参加考试和完成项目。

Python 中的函数是"**一等函数**"，所谓一等函数指的就是：函数可以赋值给变量，函数可以作为函数的参数，函数也可以作为函数的返回值。把一个函数作为其他函数的参数或返回值的用法，我们通常称之为"**高阶函数**"。

本讲我们按由易到难的顺序，依次介绍函数作为数据、把函数作为参数、内置的高阶函数、偏函数和装饰器。（Lambda 函数的写法已经在《16.函数使用进阶》中讲过，本讲不再重复。）

### 函数也可以赋值给变量

在 Python 中，函数是一个对象，我们可以把它赋值给一个变量，代码如下所示。

```python
def say_hello():
    """打招呼"""
    print('hello, world!')


# 把函数赋值给变量 greet
greet = say_hello
# 调用 greet，其实调用的还是 say_hello
greet()
```

输出：

```
hello, world!
```

上面的代码只有一行输出，但有一个**特别容易搞错的地方**：`greet()` 和 `greet` 完全是两回事。

- `greet` 只是函数本身，没有执行任何代码；
- `greet()` 才是调用函数，函数体中的代码才会真正运行。

这一点在后面讲"把函数作为参数"时会反复用到，请务必记牢：**调用函数要写圆括号，把函数当数据传递则不写圆括号**。

函数既然能赋值给变量，自然也能放进列表里保存起来，代码如下所示。

```python
def say_hello():
    """打招呼"""
    print('hello, world!')


def say_goodbye():
    """道别"""
    print('goodbye, world!')


funcs = [say_hello, say_goodbye]
for func in funcs:
    func()
```

输出：

```
hello, world!
goodbye, world!
```

在上面的代码中，列表`funcs`里装的不是字符串，而是两个函数对象；`for`循环遍历时，每次取出的`func`都是一个函数，调用它就能执行对应的代码。

### 把函数作为参数传给其他函数

更进一步，我们还可以把函数作为参数**传给其他函数**。我们先定义一个"计算器"函数，它自己不决定做什么运算，而是把运算的活儿交给别人传进来的函数，代码如下所示。

```python
def calc(func, x, y):
    """由 func 决定做什么运算"""
    return func(x, y)


def add(a, b):
    """加法"""
    return a + b


def mul(a, b):
    """乘法"""
    return a * b


print(calc(add, 3, 5))  # 8
print(calc(mul, 3, 5))  # 15
```

我们来分析一下上面的代码。

调用`calc(add, 3, 5)`时，函数`add`被赋值给形参`func`，于是`calc`函数体中的`func(x, y)`就等价于`add(3, 5)`，结果是`8`；同理，调用`calc(mul, 3, 5)`时，`func(x, y)`等价于`mul(3, 5)`，结果是`15`。

> **说明**：`calc`函数只关心"把两个数交给某个函数处理"，它并不知道自己处理的是加法还是乘法，这样写的好处是**加法、乘法可以随意替换，计算流程完全不用改动**。

如果我们要对一组数字做同样的运算，可以把上面的`calc`函数改造一下，让它支持多个数字，代码如下所示。

```python
def add(a, b):
    """加法"""
    return a + b


def mul(a, b):
    """乘法"""
    return a * b


def calc_all(func, numbers):
    """把numbers中的数字依次交给func处理"""
    result = numbers[0]
    for number in numbers[1:]:
        result = func(result, number)
    return result


print(calc_all(add, [1, 2, 3, 4]))  # 10
print(calc_all(mul, [1, 2, 3, 4]))  # 24
```

上面的代码中，`numbers[0]`是列表中的第一个数字，作为初始值；`numbers[1:]`表示从第二个数字开始到末尾的所有数字（列表的切片写法）；循环中每一轮都把上一步的结果和下一个数字交给`func`处理。

细心的同学可能已经发现，我们刚刚写的`add`和`mul`跟 Python 标准库中现成的函数几乎一样。按照"**不要重复发明轮子**"的原则，我们其实可以直接使用标准库`operator`模块中提供的`add`和`mul`，代码如下所示。

```python
import operator


def calc_all(func, numbers):
    """把numbers中的数字依次交给func处理"""
    result = numbers[0]
    for number in numbers[1:]:
        result = func(result, number)
    return result


print(calc_all(operator.add, [1, 2, 3, 4]))  # 10
print(calc_all(operator.mul, [1, 2, 3, 4]))  # 24
```

### 内置的高阶函数

Python 内置函数中有不少高阶函数，我们前面提到过的`filter`和`map`就是其中最常用的两个。

- `map`的作用是**映射**：把序列中的每一个元素交给指定的函数处理，得到一批新的结果；
- `filter`的作用是**过滤**：把序列中的元素交给指定的函数判断，只保留判断结果为真的那些元素。

我们还是用"去掉奇数、把偶数平方"这个例子来看，代码如下所示。

```python
def is_even(num):
    """判断num是不是偶数"""
    return num % 2 == 0


def square(num):
    """求平方"""
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
# 先用filter过滤掉奇数，再用map对剩下的偶数求平方
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

上面的代码是"先过滤、再映射"，写在一起有点长。我们可以把它拆成两步来读，理解起来会轻松很多，代码如下所示。

```python
def is_even(num):
    """判断num是不是偶数"""
    return num % 2 == 0


def square(num):
    """求平方"""
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
even_nums = list(filter(is_even, old_nums))  # [12, 8, 60, 52]
print(even_nums)
new_nums = list(map(square, even_nums))  # [144, 64, 3600, 2704]
print(new_nums)
```

> **提示**：`filter`和`map`返回的都不是列表，而是"惰性求值"的对象，要得到真正的列表，需要用`list()`把它包一层。

当然，完成上面代码的功能，还有一种更简单直观的写法，那就是我们之前学过的**列表生成式**，代码如下所示。

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
print(new_nums)  # [144, 64, 3600, 2704]
```

在日常开发中，如果某个任务用列表生成式能写得清楚明白，就优先用列表生成式；只有当处理逻辑本身就需要复用一个函数时，才考虑`map`和`filter`。

我们再来讨论一个内置函数`sorted`，它可以实现对容器型数据类型（如：列表、字典等）元素的排序。我们之前讲过`list`类型的`sort`方法，它实现了对列表元素的排序，`sorted`函数从功能上来讲跟列表的`sort`方法没有区别，但它会返回排序后的列表对象，而不是直接修改原来的列表，这一点我们称之为**函数的无副作用设计**，也就是说调用函数除了产生返回值以外，不会对程序的状态或外部环境产生任何其他的影响。

使用`sorted`函数排序时，可以通过高阶函数的形式自定义排序的规则，我们通过下面的例子加以说明。

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings)
print(new_strings)  # ['apple', 'in', 'pear', 'waxberry', 'zoo']
```

上面的代码对大家来说并不陌生，但是如果希望根据字符串的**长度**而不是字母表顺序对列表元素排序，我们可以向`sorted`函数传入一个名为`key`的参数，将`key`参数赋值为获取字符串长度的函数`len`，这个函数我们在之前的课程中讲到过，代码如下所示。

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings, key=len)
print(new_strings)  # ['in', 'zoo', 'pear', 'apple', 'waxberry']
```

`sorted`函数的工作过程可以这样理解：**先用`key`指定的函数给每个元素算出一个"排序用的依据"，再按照这个依据从小到大排序**。这里`len('in')`是`2`，`len('apple')`是`5`，所以长度越短的字符串排得越靠前。

> **说明**：列表类型的`sort`方法也有同样的`key`参数，有兴趣的读者可以自行尝试。

> **说明**：Lambda 函数（匿名函数）的写法我们在《16.函数使用进阶》中已经介绍过，它可以一行写出一个简单规则，常用于`sorted`函数的`key`参数。

### 偏函数

偏函数是指固定函数的某些参数，生成一个新的函数，这样就无需在每次调用函数时都传递相同的参数。在 Python 语言中，我们可以使用`functools`模块的`partial`函数来创建偏函数。例如，`int`函数在默认情况下可以将字符串视为十进制整数进行类型转换，如果我们修改它的`base`参数，就可以定义出三个新函数，分别用于将二进制、八进制、十六进制字符串转换为整数，代码如下所示。

```python
import functools

int2 = functools.partial(int, base=2)
int8 = functools.partial(int, base=8)
int16 = functools.partial(int, base=16)

print(int('1001'))    # 1001

print(int2('1001'))   # 9
print(int8('1001'))   # 513
print(int16('1001'))  # 4097
```

不知大家是否注意到，`partial`函数的第一个参数和返回值都是函数，它将传入的函数处理成一个新的函数返回。通过构造偏函数，我们可以结合实际的使用场景将原函数变成使用起来更为便捷的新函数。

### 装饰器

Python 语言中，装饰器是"**用一个函数装饰另外一个函数并为其提供额外的能力**"的语法现象。装饰器本身是一个函数，它的参数是被装饰的函数，它的返回值是一个带有装饰功能的函数。前面我们学习过，装饰器本质上就是一个高阶函数。

假设有名为`download`和`upload`的两个函数，分别用于文件的上传和下载，如下所示。

```python
import random
import time


def download(filename):
    """下载文件"""
    print(f'开始下载{filename}.')
    time.sleep(random.random() * 6)
    print(f'{filename}下载完成.')


def upload(filename):
    """上传文件"""
    print(f'开始上传{filename}.')
    time.sleep(random.random() * 8)
    print(f'{filename}上传完成.')


download('MySQL从删库到跑路.avi')
upload('Python从入门到住院.pdf')
```

> **说明**：上面的代码用休眠一段随机时间的方式模拟了下载和上传文件需要花费一定的时间，并没有真正的联网上传下载文件。用 Python 语言实现联网上传下载文件也非常简单，后面我们会讲到相关的知识。

现在有一个新的需求，我们希望知道调用`download`和`upload`函数上传下载文件到底用了多少时间。如果在每个函数里都写一遍"记录开始时间—执行函数—记录结束时间—计算时间"的代码，就会出现大量重复代码。有编程经验的人都知道，**重复的代码是万恶之源**，那么有没有办法在不写重复代码的前提下记录下函数的执行时间呢？在 Python 语言中，装饰器就是解决这类问题的最佳选择。

```python
import time


def record_time(func):
    """装饰器：记录被装饰函数的执行时间"""

    def wrapper(*args, **kwargs):
        # 在执行被装饰的函数之前记录开始时间
        start = time.time()
        # 执行被装饰的函数并获取返回值
        result = func(*args, **kwargs)
        # 在执行被装饰的函数之后记录结束时间
        end = time.time()
        # 计算和显示被装饰函数的执行时间
        print(f'{func.__name__}执行时间: {end - start:.2f}秒')
        # 返回被装饰函数的返回值
        return result

    return wrapper
```

`record_time`函数的参数`func`代表了一个被装饰的函数，函数里面定义的`wrapper`函数是带有装饰功能的函数，它会执行被装饰的函数`func`，同时还需要返回函数执行的返回值。`record_time`函数最终会返回这个带有装饰功能的函数`wrapper`并通过它替代原函数`func`。

使用上面的装饰器函数有两种方式，第一种方式就是直接调用装饰器函数，传入被装饰的函数并获得返回值，我们可以用这个返回值直接替代原来的函数，代码如下所示。

```python
download = record_time(download)
upload = record_time(upload)
download('MySQL从删库到跑路.avi')
upload('Python从入门到住院.pdf')
```

在 Python 中，使用装饰器还有更为便捷的**语法糖**（编程语言中添加的某种语法，这种语法对语言的功能没有影响，但是使用更加方便，代码的可读性也更强，我们将其称之为"语法糖"或"糖衣语法"），可以用`@装饰器函数`将装饰器函数直接放在被装饰的函数上，效果跟上面的代码相同。我们把完整的代码为大家罗列出来，大家可以再看看我们是如何定义和使用装饰器的。

```python
import random
import time


def record_time(func):
    """装饰器：记录被装饰函数的执行时间"""

    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f'{func.__name__}执行时间: {end - start:.2f}秒')
        return result

    return wrapper


@record_time
def download(filename):
    print(f'开始下载{filename}.')
    time.sleep(random.random() * 6)
    print(f'{filename}下载完成.')


@record_time
def upload(filename):
    print(f'开始上传{filename}.')
    time.sleep(random.random() * 8)
    print(f'{filename}上传完成.')


download('MySQL从删库到跑路.avi')
upload('Python从入门到住院.pdf')
```

上面的代码，我们通过装饰器语法糖为`download`和`upload`函数添加了装饰器，被装饰后的`download`和`upload`函数其实就是我们在装饰器中返回的`wrapper`函数，调用它们其实就是在调用`wrapper`函数，所以才有了记录函数执行时间的功能。

如果希望在代码的某些地方去掉装饰器的作用而执行原函数，那么在定义装饰器函数的时候，需要做一点点额外的工作。Python 标准库`functools`模块的`wraps`函数也是一个装饰器，我们将它放在`wrapper`函数上，这个装饰器可以帮我们保留被装饰之前的函数，这样在需要取消装饰器时，可以通过被装饰函数的`__wrapped__`属性获得被装饰之前的函数。

```python
from functools import wraps


def record_time(func):
    """装饰器：记录被装饰函数的执行时间"""

    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f'{func.__name__}执行时间: {end - start:.2f}秒')
        return result

    return wrapper
```

**装饰器函数本身也可以参数化**，简单的说就是装饰器也是可以通过调用者传入的参数来进行定制的，这个知识点我们在后面用到的时候再为大家讲解。

前面讲递归时提到过，递归版的斐波那契数列执行性能很差，除了改用循环之外，还有一个更省事的办法，就是用`functools`模块中的`lru_cache`装饰器给递归函数加上缓存。

```python
from functools import lru_cache


@lru_cache()
def fib1(n):
    """递归计算第n个斐波那契数"""
    if n in (1, 2):
        return 1
    return fib1(n - 1) + fib1(n - 2)


for i in range(1, 31):
    print(i, fib1(i))
```

> **提示**：`lru_cache`函数是一个带参数的装饰器，所以上面代码中`lru_cache`后面要跟上圆括号。`lru_cache`函数有一个非常重要的参数叫`maxsize`，它可以用来定义缓存空间的大小，默认值是128。

### 知识点总结

本讲是**提高部分**，核心是"**函数也是数据**"，掌握这一点，很多 Python 的写法就自然能看懂了。

- **概念**：Python 中的函数是**一等函数**，可以赋值给变量、放进容器、作为参数传给其他函数，也可以作为函数的返回值。把函数作为参数或返回值的函数称为**高阶函数**；**装饰器**是 Python 的特色语法，本质上是一个高阶函数。（Lambda 函数的写法见《16.函数使用进阶》。）
- **操作方法**：调用函数写`func()`，把函数当数据传递写`func`（不写圆括号）；`map`做映射、`filter`做过滤，二者返回的惰性对象需要用`list()`转换；`sorted`的`key`参数指定排序依据，`key=len`即按长度排序；`functools.partial`用来创建偏函数；`@装饰器名`是装饰器的语法糖写法。
- **代码要点**：`calc(func, x, y)`中`func(x, y)`等价于把传进来的函数调用一次；`calc_all`中`numbers[0]`作初始值、`numbers[1:]`用切片取出剩余元素；装饰器函数返回`wrapper`，并通过`functools.wraps`保留原函数的`__name__`等属性。
- **命名规则**：自定义函数名沿用与变量一致的命名规则，见名知意。
- **注意事项**：`filter`和`map`的结果要记得用`list()`包裹；能用列表生成式写清楚的任务优先用列表生成式；装饰器是本讲的难点，务必先理解"函数可以作为参数和返回值"再来看它。
- **学习重点**：能看懂"函数作为参数"这种写法，并能自己写出把函数赋值给变量、把函数传给其他函数的简单例子；理解`map`、`filter`、`sorted(key=...)`三个内置高阶函数的用途，能根据场景选择合适的写法；装饰器作为进阶内容，可以在掌握前面知识后再回头攻克。
